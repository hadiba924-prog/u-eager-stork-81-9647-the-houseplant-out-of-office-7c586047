An entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) bounty **The Houseplant Out-of-Office**: write the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer.

## The entry

> Out of office. I'm a cactus, day 214 without water. I've begun photosynthesizing spite. Leave a message after the wilt.

A cactus, 214 days unwatered, has moved past hope and started photosynthesizing spite instead. It keeps the out-of-office shape and lets the plant's own biology — water, photosynthesis, wilting — carry the joke.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline. It guards the gate itself: the line must be a single line of 1–120 characters.

```sh
node main.ts
```
